# Architecture

![Phylax architecture](images/architecture.webp)

Phylax spans two codebases. `phylax-subnet` is the decentralized part: the miner
and validator neurons, the round model, the sandbox, and the scoring code.
`phylax-server` is the product layer (marketplace, rentals) and is off the
protocol's critical path.

## The design decision

The miner submits an agent, and the validators run it. Because the network holds
the artifact, the evaluated agent is the served agent; because the network
controls execution, proof of execution is generated by the validator and cannot
be fabricated; because every validator runs the same agents on the same tasks, a
dishonest validator is visible; and because rounds, task selection, and consensus
come from the chain, no central party is trusted for any of it.

## Module map

| Path | Role |
|---|---|
| `neurons/miner.py` | axon neuron: serves the signed, hash pinned agent submission |
| `neurons/validator.py` | round loop: fetch agents, derive tasks, execute, score, set weights |
| `phylax/protocol.py` | `AgentSynapse`: the submission a validator fetches |
| `phylax/rounds.py` | round boundaries, the round seed, deterministic task selection |
| `phylax/screening.py` | agent similarity detection against copied submissions |
| `phylax/analysis/` | scoring spine, proof verification, capability taxonomy, per track evaluators |
| `phylax/harness/runner.py` | runs one agent on one task (docker for validators) |
| `phylax/harness/executor.py` | the network isolated jail, plus the probe file observation |
| `phylax/harness/inference_proxy.py` | metered LLM egress for the jailed sandbox |
| `phylax/harness/corpus.py` | loads the labelled benchmark; ground truth never ships to agents |
| `phylax/utils/hashing.py` | canonical JSON, SSSA digest, submission digest |

## The synapse

| Synapse | Direction | Carries |
|---|---|---|
| `AgentSynapse` | validator to miner | the miner's submission: code, entrypoint, image + digest, inference key, agent hash, and the miner's signature over the submission digest |

There is no task dispatch synapse: validators do not send tasks to miners.
Miners gate the synapse to callers holding a validator permit.

## The round

Rounds are block windows per track (`phylax/rounds.py`). At the start block the
validator fetches and verifies each miner's submission (signature over the
submission digest, hash pin, screening for size, entrypoint, and image pin),
derives the task set from the start block hash, executes every agent on every
task `r` times inside the docker jail with the per track timeout, scores, and
sets graduated weights above the quality threshold.

## Isolation

Agents run only inside the jail: an internal docker network whose sole egress is
the metered inference proxy, with CPU, memory, and PID caps and capabilities
dropped. The validator refuses to evaluate at all if the jail is unavailable.
After each run, the executor itself checks the probe file inside the container,
so at least one probe effect is validator observed rather than agent reported.

## Eligibility and consensus

Validator eligibility is on chain and permissionless: a permit granted by stake
weight and positive vtrust from actively setting weights. Each validator sets
weights independently and Yuma consensus reconciles them by stake weighted median
with clipping.
